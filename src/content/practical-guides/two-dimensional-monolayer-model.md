This worked example creates an illustrative 2H-MoS2 monolayer with ASE. It demonstrates model identity and structural checks. It is not derived from an experimental file, does not contain a DFT-relaxed lattice, and does not support a stability or property claim.

## Declare the origin honestly

The source object is generated by a documented builder rather than downloaded from a database:

```python
from ase.build import mx2

monolayer = mx2(
    "MoS2",
    kind="2H",
    a=3.18,
    thickness=3.19,
    size=(2, 2, 1),
    vacuum=8.0,
)
```

The record should therefore say `generated illustrative structure`, identify ASE and its version, and preserve every builder argument. It should not describe the object as an experimentally measured monolayer.

The numerical values are demonstration inputs selected for a bounded executable example. They are not certified experimental values, converged DFT settings, or recommendations for another material.

## Read the builder arguments as model decisions

The call establishes:

- chemical formula `MoS2`;
- the requested `2H` layer type;
- one in-plane lattice parameter;
- the vertical separation used by the builder;
- a two-by-two in-plane repetition;
- one layer along the third direction;
- explicit empty-cell length around the layer.

Changing any of these can change the model. Increasing the lateral size without adding a perturbation can be a representation change. Changing layer type, composition, strain, thickness, defect content, stacking, or periodicity changes the physical hypothesis.

## Verify periodicity and composition

The executable example checks:

```python
assert monolayer.pbc.tolist() == [True, True, False]
assert len(monolayer) == 12
assert monolayer.get_chemical_symbols().count("Mo") == 4
assert monolayer.get_chemical_symbols().count("S") == 8
```

The periodic-boundary flags express a two-dimensional model in ASE. A later electronic-structure code may still use a three-dimensional periodic cell and require its own electrostatic treatment. The coordinate file alone does not preserve that intention unless periodicity and boundary choices are recorded separately.

## Measure the actual geometry

The example calculates:

- the full cell matrix;
- the minimum and maximum atomic z coordinates;
- the atomic z extent;
- the total empty-cell length along z;
- the in-plane area;
- the chemical formula and atom count.

This is more informative than reporting only the `vacuum` argument. The actual object position, atomic extent, and cell length determine the empty region represented by the model.

## Preserve a minimal model identity

A reconstructable record for this example is:

```text
origin: generated illustrative structure
builder: ase.build.mx2
software: ASE 3.29.0
formula: MoS2
kind: 2H
builder parameters: a, thickness, size, vacuum
periodicity: true, true, false
output checksum or stable artifact identifier
execution script and result summary
```

A production model would additionally require a defensible material source, relation to bulk or experimental structure, model-selection rationale, convergence evidence, and a versioned electronic-structure method.

## What this example does not establish

The page and companion script do not establish:

- that the chosen polytype is the relevant phase;
- that the lattice or thickness values are accurate;
- that the cell or vacuum is converged;
- that the monolayer is dynamically or thermodynamically stable;
- that a substrate-free isolated layer represents an experiment;
- that any electronic, optical, vibrational, transport, or superconducting property follows.

Those questions require later method selection, numerical convergence, reference-state calculations, and target calculations.

## Why this belongs under model construction

The output is an explicit atomistic hypothesis with declared dimensionality, composition, cell, and lineage. It is ready to be passed to method selection and convergence planning, but it is not yet a validated calculation input or result.

This separation is the purpose of the worked example: constructing a clean-looking monolayer file is easy; preserving what it represents and what remains unknown is the scientific task.
